# XiaomiSalesMM
App Android para llevar ventas y comisiones. Los datos se guardan en el móvil.

## Obtener el APK
1. Sube esta carpeta a un repositorio de GitHub.
2. Ve a **Actions → Build APK → Run workflow** (también se ejecuta solo al hacer push).
3. Al terminar, descarga **XiaomiSalesMM-apk** en la sección *Artifacts* del run.
4. Pasa el APK al móvil e instálalo (permite "instalar apps de origen desconocido").

## Logo propio
Para mostrar el logo en la cabecera, copia tu imagen como `app/src/main/assets/logo.png`.
